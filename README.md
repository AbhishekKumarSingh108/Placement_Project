# 🎓 College Placement Prediction

A Machine Learning project that predicts whether a student is likely to get placed based on academic and skill-related information.

## 🌐 Live Demo

👉 https://placement-project.streamlit.app/

## 📌 About the Project

The model predicts placement using:

- IQ
- CGPA
- Communication Skills
- Projects Completed
- Internship Experience

The project uses a Machine Learning pipeline for preprocessing and classification, and the trained model is deployed using Streamlit.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit
- Git & GitHub
